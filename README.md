## 🇬🇧 English Version

### About This Project
This repository contains the validated codebase for my travel agency homepage project (`Booki`), completed as part of my front-end web development training. The primary objective was to transform complex design mockups into a fully responsive, pixel-perfect, and accessible web page using modern HTML5 and CSS3 techniques.

### What I Did
* **Design-to-Code Mastery:** Expertly translated multi-device Figma mockups (Mobile, Tablet, and Desktop) into production-ready front-end components, meticulously adhering to typography, spacing, and brand guidelines.
* **Responsive Web Design (RWD):** Implemented fluid layouts, media queries, and flexible container sizing to guarantee a seamless user experience across all screen sizes and viewports.
* **Front-End Architecture:** Built custom UI components (such as lodging cards, activity grids, and filter buttons) from scratch using clean, semantic HTML and modular CSS stylesheets.
* **Environment Setup:** Configured a professional front-end development workflow from scratch, managing assets, version control, and local testing.

### Skills & Tools Used
* **HTML5:** Semantic markup and structured layout composition.
* **CSS3:** Advanced styling, flexbox/grid layout systems, media queries, and responsive design patterns.
* **Figma:** Deep inspection of design specifications, extracting layout dimensions, color palettes, and graphical assets across all device breakpoints.
* **Visual Studio Code:** Local development environment, extension configuration, and code testing.

## 🇫🇷 Version Française

### À propos de ce projet
Ce dépôt contient le code validé de la page d'accueil d'une agence de voyage (`Booki`), réalisé dans le cadre de ma formation en développement web. L'objectif principal était de concevoir une interface web responsive et fidèle aux spécifications graphiques en transformant des maquettes de design en code fonctionnel.

### Ce que j'ai fait
* **Traduction fidèle des maquettes (Design-to-Code) :** Transformation de maquettes Figma multi-supports (Mobile, Tablette et Desktop) en composants web interactifs et responsives, dans le strict respect de la charte graphique.
* **Développement Responsive (RWD) :** Mise en œuvre de grilles flexibles, de requêtes médias (media queries) et de structures adaptatives pour garantir une expérience utilisateur fluide sur tous les types d'écrans.
* **Création de composants UI :** Développement de blocs d'interface sur mesure (cartes d'hébergement, grilles d'activités, filtres) en structurant un code HTML sémantique et un style CSS modulaire.
* **Configuration de l'environnement :** Mise en place d'un workflow de développement front-end professionnel pour l'intégration des assets et la gestion du projet.

### Compétences et Outils Utilisés
* **HTML5 :** Balisage sémantique et architecture de page rigoureuse.
* **CSS3 :** Mise en page avancée (Flexbox/Grid), design adaptatif et feuilles de style modulaire.
* **Figma :** Utilisation approfondie pour analyser les dimensions, extraire les assets et inspecter les comportements responsive selon les breakpoints.
* **Visual Studio Code :** Environnement de développement et éditeur de code principal.
